# Athlete-Injury-Prediction


This repository replicates the methodology described in:

Li et al. (2024). *A Big Data Approach to Forecast Injuries in Professional Sports Using Support Vector Machine*.  
Mobile Networks and Applications, Springer.

## Dataset
- Collegiate athlete injury dataset
- Binary injury outcome
- Workload and participation features

## Methodology
- Standardization
- Train/Validation/Test split (70/15/15)
- Recursive Feature Elimination (RFE)
- Support Vector Machine (RBF kernel)

## Execution
Run `svm_injury_prediction.ipynb`
